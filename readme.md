### Spreent Academy — design-led landing page

*Astro · TypeScript (strict) · SCSS/BEM · Vitest · Playwright*

**PageSpeed 100 · 100 · 100 · 100** with 18 motion effects running — every one guarded by `prefers-reduced-motion`.
